# eu.fbtools-BasicJinglePack

A small pack of short AI-generated jingles for streams, podcasts, videos, and rapid prototyping.

## Included

- Multiple short jingles (FLAC)
- Preview files and a metadata manifest
- LICENSE (CC0 1.0) — public-domain dedication permitting reuse without attribution

## Usage

- Edit, remix, or layer as needed — no attribution required under CC0.
